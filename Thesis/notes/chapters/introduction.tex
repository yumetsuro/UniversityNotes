Nowadays, Artificial Intelligence (AI) became the main driver of innovation in many fields, at the point that the growth of research

in order to perform \textit{inference} and return prediction on unseen data. \newline

Reservoir Computing (RC) is a computational framework introduced in the early 2000s with Echo State Networks (ESN) \cite{jaeger2001echo} and
Liquid State Machines (LSM) \cite{fernando2003pattern}, these models aims to simplify the training of RNNs and at the same time exploit inherent dynamical properties of real world physical system in order to
obtain a \textit{"reservoir"} of rich dynamics that can be used to solve complex task, at the same time we reduce the training cost by only performing a linear regression on the output layer.
The main idea is that usally we need to train the recurrent connection in the network, but RC avoid this by using fixed high dimensional dynamycal system, that project the input signal into an high dimensional space,
where a simple approach as pseudoinverse or ridge regression is sufficient to learn the linearized representation of the input signal. \newline
