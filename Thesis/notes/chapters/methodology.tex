\label{chap:methodology}
After having discussed all the background concepts and related works, we can now move on to the methodology used in this work.
In this chapter, we present the idea to treat deep reservoir networks as \emph{modular reservoir} architectures. 
Rather than treating the reservoir as a monolithic recurrent system, we interpret each layer of the deep reservoir as an independent computational module that processes inputs and exchanges information with others through structured interconnections.

\section{Modularity in RNNs}
\label{sec:method:modularity}
In dynamical systems theory, a system is said to be \emph{modular} if it can be decomposed into distinct 
subsystems (modules), each of which has its own internal dynamics while also interacting with other modules.
Such a composition allows for a complex global behaviour to emerge from the interactions of simpler components.
Analyzing the system in terms of global dynamics and being capable of modifying it by working on single parts can provide control on information flow and interpretability benefits.

Modularity has been extensively studied in neuroscience, where large-scale brain networks exhibit modular organization with specialized regions that act as hubs for information integration.
Empirical studies from \cite{bullmore2009complex} have shown that neural systems are composed of densely connected subnetworks that interact globally as a sparse system, supporting
both the integration of information and specialized processing 

More generally, studies in complex systems and network dynamics have shown that modular organization 
can enhance robustness by inducing a separation of time scales, such that dynamical processes remain
 confined within subsystems for extended periods before spreading globally. 
 This structure allows perturbations to decay locally and supports stable large-scale 
 dynamics under appropriate stability conditions \cite{Lambiotte_Schaub_2022}.

\section{Deep Modular Reservoirs} 
\label{sec:method:deep_modular}
We model a deep reservoir as a composition of $L$ layers or modules. 
Each module $l\in\{1,\dots,L\}$ has state $\mathbf{h}^{(l)}(t)\in\mathbb{R}^{n_l}$ and internal recurrent connectivity $\mathbf{W}^{(l)}$.
The key methodological contribution is to compare two architectures:

\begin{itemize}
    \item \textbf{Deep Cycle Reservoir} where we employ \emph{cycle/ring} recurrent topology, inspired by Simple Cycle Reservoirs (SCR), to provide strong memory traces with minimal parameters.
    \item \textbf{Deep Antisymmetric Reservoir} with \emph{forward and backward} coupling between adjacent modules, designed to promote stable dynamics and improve gradient-free memory propagation.

\subsection{Global state and dynamics}
Let $\mathbf{H}(t)$ be the global reservoir state at time $t$ obtained by feeding the input $\mathbf{u}(t)$ into the first module and propagating through the layers.
By stacking the states of all modules, we have the final feature vector used for the readout:
\begin{equation}
    \mathbf{H}(t) = \bigl[
    \mathbf{h}^{(1)}(t),
    \mathbf{h}^{(2)}(t),
    \mathbf{h}^{(L)}(t)
    \bigr] \in \mathbb{R}^{N}; \quad N = \sum_{l=1}^L n_l.
    \label{eq:method:feature_concat}
\end{equation}
Where $N$ is the total reservoir size and $n_l$ is the size of module $l$.
The global dynamics of the reservoir can be written in the compact form:
obtained after the application of the activation function and leaky integration.

We define the pre-activation vector
\begin{equation}
    \label{eq:method:pre_activation}
\mathbf z(t+1) =
\mathbf W_{\text{tot}} \mathbf H(t)
+ \mathbf W_{\text{in}} \mathbf u(t+1)\footnote{\text{This input term is just for the input, not the inter-layer connection}}
+ \mathbf b .
\end{equation}

The reservoir state is then updated as
\begin{equation}
\label{eq:method:state_update_general}
\mathbf H(t+1) =
(1-\alpha)\mathbf H(t) + \alpha \tanh(\mathbf z(t+1)).
\end{equation}

where $\tanh(\cdot)$ acts element-wise on the state vector and
$\mathbf{W}_{\text{tot}} \in \mathbb{R}^{N \times N}$ encodes both intra-module and inter-module connections.
For 1 layer Leaky-ESN, the $\mathbf{W}_{\text{tot}}$ reduces to the standard recurrent weight matrix $\mathbf{W}_{\text{rec}}$.

\section{Deep Cycle Reservoir}
\label{sec:method:cycle}
We introduce \textbf{Deep Cycle Reservoir} (DCR) as a class of deep reservoir, inspired by methods discussed in sec \ref{sec:method:cycle}.
We tried to apply modularity concepts to a delayed version of SCR.

\subsection{Discussion}
In a conventional DeepESN, information flows unidirectionally 
from the input through the stacked reservoirs to the readout.
But it lacks a feedback path that might allow higher‑level temporal abstractions
to influence lower levels. A cyclic reservoir introduces a feedback connection 
from the output of the last reservoir layer back to the first layer.
The motivation for closing the loop is to allow information processed at deeper layers 
(capturing longer‑term or low‑frequency features) to inform the processing of new inputs.
This can enrich the reservoir dynamics and, in principle, improve tasks requiring both short and long‑term memory.

However, an instantaneous cycle where the output of the deepest layer at time step $t$
is fed directly into the first layer at the same time step $t$, require to know the current state of the deepest layer, which for
the first timestep is not available.\newline
In the discrete‑time update equation of an ESN, the next state depends on the previous 
state and the current input; if the current state of a high‑level layer 
instantly modifies the state of the first layer, it creates a dependency loop on its own output.  
A naive solution consists of using a delayed step as a cycle connection.

We also allow each layer to receive the input directly because we don't want the delayed information to overwrite the current input.
Notably, this results in losing the distance between input and deeper layers, as happens for deepESN‑IA \cite{GALLICCHIO201787},
where the intrinsic time‑scale separation is attenuated. \todo{Qui magari posso mettere i plot della distanza tra stati}

\subsection{Stability analysis of Deep Cycle Reservoir}
\label{sec:method:dcr_analysis}
In this section, we extend the analysis of standard ESN dynamics to the proposed DCR.
We follow the theoretical framework established in \cite{gallicchio2017echo}, 
 adapting the study of stability to the specific case of cyclic modular connectivity.
Is important to address the dynamics of such systems, since it affects both the capability to learn relevant information and
keeping past information in the memory without losing it too quickly.
We will study the stability of DCR by linearizing its dynamics and deriving necessary conditions for ESP.

Finally, we analyze the spectral radius of the system's Jacobian.
Thus need to derive the Jacobian matrix $\mathbf{J}$ of equation \ref{eq:method:cycle_dynamics}.
\subsubsection{Echo State Property of Deep Cycle Reservoir}
\label{sec:method:esp_def}
We introduce the notation $\hat{F}$ to denote the iterated version of the DCR global state transition function defined in Eq. \ref{eq:method:state_update_general}.

Given an input sequence of arbitrary finite length $N_s$, denoted as $\mathbf{s} \in (\mathbb{R}^{N_U})^*$, and a global initial state $\mathbf{H} \in \mathbb{R}^{N}$, the function 
$\hat{F}(\mathbf{s}, \mathbf{H})$ represents the global state of the network after being driven 
by the sequence $\mathbf{s}$ starting from $\mathbf{H}$.

The iterated map is defined recursively:
\begin{equation}
\label{eq:method:iterated_map}
\hat{F} : (\mathbb{R}^{N_U})^* \times \mathbb{R}^{N} \to \mathbb{R}^{N}
\end{equation}

\begin{equation}
\hat{F}(\mathbf{s}, \mathbf{H}) = 
\begin{cases} 
\mathbf{H} & \text{if } \mathbf{s} = [] \\
F(\mathbf{u}(k), \hat{F}([\mathbf{u}(1), \dots, \mathbf{u}(k-1)], \mathbf{H})) & \text{if } \mathbf{s} = [\mathbf{u}(1), \dots, \mathbf{u}(k)]
\end{cases}
\end{equation}
where $[]$ denotes the null sequence.

Accordingly, the ESP for the Deep Cycle Reservoir is defined as follows:

\begin{definition}[Echo State Property of DCR]
\label{def:esp_dcr}
Assuming a Deep Cycle Reservoir whose global dynamics are governed by the function $F$. 
The network has \emph{echo states} if for any input sequence of length $k$, $\mathbf{s}_k = [\mathbf{u}(1), \dots, \mathbf{u}(k)]$, 
and for all pairs of initial global states $\mathbf{H}, \mathbf{H}' \in \mathbb{R}^{N}$, then:
\begin{equation}
||\hat{F}(\mathbf{s}_k, \mathbf{H}) - \hat{F}(\mathbf{s}_k, \mathbf{H}')|| \to 0 \quad \text{as} \quad k \to \infty.
\end{equation}
\end{definition}

From a dynamical systems perspective, the DCR implements an input-driven discrete-time non-linear dynamical system $F$,
 mapping the external input $\mathbf{u}(t)$ and the global state $\mathbf{H}(t-1)$ to the next state $\mathbf{H}(t)$:
\begin{equation}
    \mathbf{H}(t) = F(\mathbf{u}(t), \mathbf{H}(t-1)).
\end{equation}
As defined in Eq. \ref{eq:method:cycle_dynamics}, the global state transition is 
governed by the global weight matrix $\mathbf{W}_{\text{DCR}}$.

\section{Deep Antisymmetric Reservoir}
\label{sec:method:antisymmetric}
In this section, we present the \textbf{Deep Antisymmetric Reservoir} (DAR), another modular deep reservoir,
where modules are coupled such that information can flow bidirectionally between adjacent layers. We took inspiration from well-known properties of
skew-symmetric matrices in dynamical systems. Other works have explored antisymmetric matrices applied to RC as in \cite{kozachkov2022rnns}.
\subsection{Discussion}
Antisymmetric (or skew-symmetric) connectivity can constrain the dynamics in a way that mitigates exploding trajectories.
Intuitively, purely antisymmetric linear dynamics preserve energy in continuous time; in practice, 
discrete-time nonlinear systems may still benefit from the improved conditioning and stability induced by such constraints.

As discussed previously in sec. \ref{sec:antisymmetric_rnn}, keeping a system in a critical regime, preserves long-term dependancies 
and helps the system to maintain stability over perturbations. Other works tried this idea on RC, as in \cite{gallicchio2024euler}, where the author
proposes to construct the reservoir with an antisymmetric recurrent matrix.
\newline
Our idea, instead, consist of dividing the modules in two parts: the first extends the memory about past information with the antisymmetric coupling,
this should help to promote a stable information flow between layers, and the second part integrates the new input to the system through recurrent connections, each module can still retain past
information from adjacent layers along the new information coming from the input.

\subsection{Information Flow in DAR}
With the DAR, we have a hierarchical information flow, where each module receives input from the previous layer's state at the current time step.
To improve memory retention and stability, the coupling acts on the previous time step states of adjacent layers.
The input to the $l$-th module, denoted $\mathbf{h}^{(l)}(t)$, is defined as:
\begin{equation}
    \mathbf{h}^{(l)}(t) = 
    \begin{cases} 
        \mathbf{u}(t) & \text{if } l = 0 \\
        \mathbf{h}^{(l-1)}(t) & \text{if } l > 1 
    \end{cases}
\end{equation}
This ensures that information from the external input $\mathbf{u}(t)$ propagates through the entire depth of the network at the current time step $t$, 
allowing each module to process both current and past information from neighboring layers.
\subsection{Module Dynamics}

\begin{equation}
\label{eq:method:antisym_leak}
\begin{split}
    \mathbf{h}^{(l)}(t) = (1 - \alpha) \mathbf{h}^{(l)}(t-1) + \alpha \tanh\Bigg( & \underbrace{W_{\text{in}}^{(l)} \mathbf{h}^{(l-1)}(t)}_{\text{Current Input}} \\
    & + \underbrace{(W_{\text{rec}}^{(l)} - \gamma I) \mathbf{h}^{(l)}(t-1)}_{\text{Local Memory}} \\
    & + \underbrace{\epsilon \left( C^{(l)} \mathbf{h}^{(l-1)}{(t-1)} - C^{\top (l)} \mathbf{h}^{(l+1)}{(t-1)} \right)}_{\text{Antisymmetric Coupling}} \Bigg)
\end{split}
\end{equation}
where we have introduced the coupling terms $(C^{(l)} - C^{\top (l)})$ for bidirectional interaction between adjacent modules with $\epsilon$ scaling
the coupling strength and a dissipation term $-I\gamma$ to the recurrent weights to control stability.

A clearer description is given by the fig. \ref{fig:antisymmetric-modular}.

\section{Deep Random Oscillators Network}
\label{sec:method:dron}
In this section, we extend the modular depth framework previously established for ESN-based reservoirs to the Random Oscillators Network (RON) architecture.
The objective is to combine the benefits of hierarchical depth with the oscillatory dynamics inherent to RONs.
Subsequently, we extend the two previously proposed structured modular architectures (cyclic and antisymmetric) to the oscillatory reservoir setting.

\subsection{Discussion}
The shallow RON architecture effectively captures long-term dependencies through its second-order oscillatory dynamics, achieving competitive performance with minimal computational overhead.
However, shallow RONs require precise hyperparameter tuning, being sensitive especially to the $\tau$ discretization parameter, to operate in an optimal dynamical regime.

In analogy to DeepESN, a \textbf{Deep Random Oscillators Network} (DeepRON) should exhibit richer temporal representations at multiple time scales, 
leveraging the hierarchical filtering of information across successive layers. 
Crucially, following the principles established in \cite{GALLICCHIO201787}, the depth-induced temporal differentiation arises naturally from the layered architecture.
This increased representational capacity, however, comes at the cost of a larger hyperparameter space.
In principle, each layer $l \in \{1, \dots, L\}$ may have distinct oscillator parameters $(\bm{\gamma}^{(l)}, \bm{\epsilon}^{(l)})$, discretization step $\bm{\tau}^{(l)}$, spectral radius $\rho^{(l)}$, and inter scaling $\omega_{inter}^{(l)}$.
To mitigate this complexity and facilitate systematic experimentation, we adopt a \emph{homogeneous layer configuration}\footnote{The same applies to the other models presented in our work.}: 
all layers share identical hyperparameters, differing only in their random initialization of the reservoir weights.
This design choice preserves the computational efficiency characteristic of reservoir computing while enabling the study of depth-induced temporal differentiation. 

\subsubsection{DeepRON Dynamics}
Let $\mathbf{y}^{(l)}_k \in \mathbb{R}^{N_l}$ and $\mathbf{z}^{(l)}_k \in \mathbb{R}^{N_l}$ denote the position and velocity states of the oscillators in layer $l$ at discrete time step $k$. \todo{Per quanto riguarda qui utilizzo k come time step per essere più consistente con la notazione del paper, dovrei usare t per i timestep ed usare la stessa notazione degli altri modelli della tesi?}
The input to each layer is defined hierarchically: layer $l=1$ receives the external input $\mathbf{u}_k$, while subsequent layers receive the state of the preceding layer, i.e., $[\mathbf{y}^{(l-1)}_k, \mathbf{z}_k^{(l-1)}]$.

The dynamics of each layer are governed by the following discretized second-order system by using the Euler method with step size $\tau$:
\begin{equation}
\label{eq:method:deepron_dynamics}
\begin{aligned}
    \mathbf{z}^{(l)}_{k+1} &= \mathbf{z}^{(l)}_k + \tau \left[ \tanh\left(\mathbf{W}^{(l)}\mathbf{y}^{(l)}_k + \mathbf{V}^{(l)}\mathbf{x}^{(l)}_{k+1} \right) - \bm{\gamma} \odot \mathbf{y}^{(l)}_k - \bm{\epsilon} \odot \mathbf{z}^{(l)}_k \right], \\
    \mathbf{y}^{(l)}_{k+1} &= \mathbf{y}^{(l)}_k + \tau \mathbf{z}^{(l)}_{k+1},
\end{aligned}
\end{equation}

Following the formulation of RON, the state of each DeepRON layer
is defined as the concatenation of position and velocity variables.
For layer $l$, we introduce the layer state
\begin{equation}
    \mathbf{X}^{(l)}_k =
    \begin{pmatrix}
        \mathbf{y}^{(l)}_k \\
        \mathbf{z}^{(l)}_k
    \end{pmatrix}
    \in \mathbb{R}^{2N_l},
\end{equation}
which fully characterises the second-order dynamics of the oscillators in that layer.

The global state of the DeepRON is then obtained by stacking the states of all layers, yielding
\begin{equation}
    \mathbf{X}_k =
    \begin{pmatrix}
        \mathbf{X}^{(1)}_k \\
        \mathbf{X}^{(2)}_k \\
        \vdots \\
        \mathbf{X}^{(L)}_k
    \end{pmatrix}
    \in \mathbb{R}^{2N},
    \quad
    N = \sum_{l=1}^{L} N_l.
\end{equation}

\section{Deep Cycle Oscillator}
\label{sec:method:dco}

The \textbf{Deep Cycle Oscillator} (DCO) extends the Deep Cycle Reservoir architecture to the oscillatory setting.
As in the DCR, a feedback connection from the deepest layer to the first layer closes a ring topology across depth.
To avoid circular dependencies at a single time step, the cycle connection operates with a unit delay.

The dynamics of the DCO are given by:
\begin{equation}
\label{eq:method:dco_dynamics}
\begin{aligned}
    \mathbf{z}^{(1)}_{k+1} &= \mathbf{z}^{(1)}_k + \tau \left[ \tanh\left(\mathbf{W}^{(1)}\mathbf{y}^{(1)}_k + \mathbf{V}^{(1)}\mathbf{u}_{k+1} + \mathbf{W}_{\text{cyc}}^{(1)}\mathbf{y}^{(L)}_k \right) - \bm{\gamma} \odot \mathbf{y}^{(1)}_k - \bm{\epsilon} \odot \mathbf{z}^{(1)}_k \right], \\
    \mathbf{z}^{(l)}_{k+1} &= \mathbf{z}^{(l)}_k + \tau \left[ \tanh\left(\mathbf{W}^{(l)}\mathbf{y}^{(l)}_k + \mathbf{V}^{(l)}\mathbf{u}_{k+1} + \mathbf{W}_{\text{cyc}}^{(l)}\mathbf{y}^{(l-1)}_k \right) - \bm{\gamma} \odot \mathbf{y}^{(l)}_k - \bm{\epsilon} \odot \mathbf{z}^{(l)}_k \right], \\
    \mathbf{y}^{(l)}_{k+1} &= \mathbf{y}^{(l)}_k + \tau \mathbf{z}^{(l)}_{k+1}, \quad l = 1, \ldots, L.
\end{aligned}
\end{equation}

Here, $\mathbf{W}_{\text{cyc}}^{(l)}$ denotes the inter-layer cycle connection matrix.
The first layer receives feedback from the last layer's state at the previous time step, $[\mathbf{y}^{(L)}_k,\mathbf{z}^{(L)}_k]$.
Each layer also receives the external input $\mathbf{u}_{k+1}$ directly, and we are using the same exact architecture shown in fig. \ref{fig:deep_cycle_reservoir}.

\section{Deep Antisymmetric Oscillator}
\label{sec:method:dao}

The \textbf{Deep Antisymmetric Oscillator} (DAO) adds antisymmetrical coupling between adjacent layers in the DeepRON architecture.

The dynamics of the DAO are governed by:
\begin{equation}
\label{eq:method:dao_dynamics}
\begin{aligned}
    \mathbf{z}^{(l)}_{k+1} = \mathbf{z}^{(l)}_k + \tau \Bigg[ & \tanh\Big((\mathbf{W}^{(l)}\mathbf{y}^{(l)}_k)- \gamma_c I) + \mathbf{V}^{(l)}\mathbf{x}^{(l)}_{k+1} + \mathbf{b}^{(l)}\Big) \\
    & - \bm{\gamma} \odot \mathbf{y}^{(l)}_k - \bm{\epsilon} \odot \mathbf{z}^{(l)}_k \\
    & + \epsilon_c \left( \mathbf{C}^{(l)} \mathbf{y}^{(l-1)}_k - (\mathbf{C}^{(l)})^\top \mathbf{y}^{(l+1)}_k \right) \Bigg], \\
    \mathbf{y}^{(l)}_{k+1} &= \mathbf{y}^{(l)}_k + \tau \mathbf{z}^{(l)}_{k+1},
\end{aligned}
\end{equation}
\todo{dovrei dare nomi diversi ai gamma ed epsilon introdotti per non confonderli con quelli degli oscillatori, va bene questa scelta oppure rischio di confondere il lettore?}
where $\mathbf{C}^{(l)} \in \mathbb{R}^{N_l \times N_{l-1}}$ is the coupling matrix from layer $l-1$ to layer $l$, 
$\epsilon_c > 0$ controls the coupling strength, and $\gamma_c \geq 0$ is a dissipation term for stability, antisymmetry
grants stability only in continuous time; in our case, discretization errors tend to produce unstable spiraling behaviour in the state space. At the same time, we gain some control over the contractility of our system, resulting in a fading memory.\todo{di questo non sono sicuro, il termine diffusivo muove verso sinistra gli autovalori quindi potrebbe anche far si che il sistema diverga comunque...}

For boundary layers, we set $\mathbf{y}^{(0)}_k = \mathbf{0}$ and $\mathbf{y}^{(L+1)}_k = \mathbf{0}$, we do the same for the velocity.


The antisymmetric structure $(\mathbf{C}^{(l)}, -(\mathbf{C}^{(l)})^\top)$ induces near-conservative dynamics between adjacent modules.
Combined with the oscillatory intra-module dynamics that are core of RONs, DAO could solve some instability problems of DeepRON,
since by introducing only purely imaginary eigenvalues, we only get rotations in the state space, moreover, the position and velocity of our oscillators 
tends to be conserved over time, lasting longer, this can have both positive and negative effects, keeping information that is not useful anymore much longer could
be detrimental to the performance, but at the same time, it could help to keep very long-term dependancies.

In this chapter, we have introduced novel deep reservoir architectures
 that extend the principles of modular depth to both standard ESN and Random Oscillators Network frameworks.

We leave a detailed stability analysis of DeepRON and other architectures for future work, 
since, for the moment, we focused on empirical evaluation.

The DCR implements a modular ring topology in which all layers can be updated in parallel, 
since each module depends only on past states of other modules rather than on their current activations.
Unlike standard DeepESNs, where temporal filtering emerges from a strictly hierarchical
feedforward stack, the DCR reinjects delayed information from the deepest layer
back to the first, thereby establishing a global memory trace. 


DAR realizes a hierarchical modular architecture 
in which neighboring layers are coupled bidirectionally through structured antisymmetric connections.
 Each module processes the current input propagated from the previous layer while exchanging 
 past state information with adjacent modules, aiming to support stable and long-range information flow across depth.

From a dynamical perspective, we have derived a necessary stability
condition based on the Jacobian spectral radius of both architectures (Eq. \ref{eq:method:nec_cond_dcr} and \ref{eq:method:nec_cond_dar}).
